# Tmux Session

A [Nova](https://nova.app) extension for using [tmux](https://github.com/tmux/tmux) as Nova's terminal shell, with each tab's session easy to open in Ghostty, iTerm, kitty or Terminal.

## Usage

Invoke via **Extensions > Tmux Session**, or search in the Command Palette:

- **Open in External Terminal** — opens one of this project's sessions in your terminal app
- **Copy Join Command** — copies a command to join a session from another terminal
- **Show All Sessions…** — lists every running session, to open, copy, rename or end one
- **Rename Session…** — gives one of this project's sessions a new name
- **End Session…** — ends one of this project's sessions and everything running in it
- **Copy Recommended tmux Settings** — copies tmux settings that suit Nova's terminal
- **Copy launchd Agent** — copies a launchd agent that keeps sessions running when Nova quits or crashes
